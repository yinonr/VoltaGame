# Settlers of Compute

*Build your AI empire. Before someone else builds theirs.*

An unofficial, Catan-inspired browser strategy game about the AI compute economy. You run an ambitious AI startup competing with three rival AI companies for Power, Networking, Land, Capital and GPUs.

> Work in progress. See `docs/HANDOFF.md` for current status.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # engine tests (Vitest)
npm run build    # production build in dist/
```
